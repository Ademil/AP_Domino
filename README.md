# AP DOMINÓ — V1

Jogo de dominó completo, responsivo, offline e instalável (PWA).
**Desenvolvido por APavan Engenharia e Consultoria.**

---

## ▶ Como executar (o mais simples possível)

1. Extraia a pasta `AP-DOMINO`.
2. Dê **duplo clique** em `index.html`.
3. O jogo abre no navegador e já é jogável.

> Funciona em Chrome, Edge, Firefox, Safari, no desktop e no celular.

### Servidor local (recomendado para PWA)

Para instalar como aplicativo, é necessário servir por HTTP:

```bash
# Na pasta do jogo:
python -m http.server 8080
# ou
npx serve .
